One-time setup on iPhone

  1. Open the Shortcuts app → tap +.
  2. Add Find Health Samples. Type: Steps. Start Date: Start of Today.
  3. Add Calculate Statistic → Sum.
  4. Add Open URLs. URL: https://papicurls.github.io/diet-hub/?steps= then tap and insert the Sum variable right after =.
  5. Name it Diet Hub Steps and tap Done. Allow Health access when it asks.

After that, tap the button below whenever you want Diet Hub to pull today’s steps. Optional: Shortcuts → Automation → Time of Day, run this shortcut daily.
